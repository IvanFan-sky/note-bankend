### Note APP
这是一个基于Spring Boot的基础项目

## 技术栈

- Spring Boot 2.7.6
- MyBatis-Plus 3.5.2
- MySQL 8.0
- Knife4j 3.0.3
- Hutool 5.8.10
- Lombok

## 功能特性

### 1. 用户管理模块
- 用户CRUD操作
- 分页查询支持
- 条件筛选（用户名、角色）
- 逻辑删除

### 2. 笔记管理模块
- 笔记CRUD操作
- 分页查询支持
- 条件筛选（用户ID、标题、类型）
- 笔记置顶功能
- Markdown支持
- 逻辑删除

### 3. 标签管理模块
- 标签CRUD操作
- 分页查询支持
- 条件筛选（用户ID、标签名）
- 笔记-标签关联管理
- 标签颜色支持
- 逻辑删除

### 4. 统一响应处理
- 统一返回格式
- 全局异常处理
- 业务异常处理
- 参数校验异常处理

### 5. 日志管理
- 分环境日志配置
- 错误日志独立存储
- 业务日志分离
- 控制台彩色日志输出

### 6. API文档
- Knife4j接口文档
- 接口分组管理
- 详细的接口说明
- 在线调试功能

## 开发规范
1. 统一响应格式
2. 统一异常处理
3. 统一日志处理
4. 统一API文档
